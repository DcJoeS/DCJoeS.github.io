# DCJoeS.github.io

Personal portfolio and project landing page for Joe Sapletal, GISP. The root
`index.html` highlights GIS, mapping, and terrain visualization work.

## Homepage maintenance

- Edit `index.html` for profile copy, social links, and featured projects.
- Keep the visual assets in `images/backgrounds`, `images/hero`,
	`images/cards`, and `images/icons`.
- For a new featured project, update the destination URL, title, description,
	image alt text, and image dimensions together.
- Keep external links keyboard accessible and use `target="_blank"`
	with `rel="noopener noreferrer"` when they open a new tab.
- Test the page at a narrow mobile width and a desktop width after content or
	asset changes. Also tab through every link and check that the page remains
	usable with reduced motion enabled.

The site is a static GitHub Pages project. The older `index_old*.html` files
and subdirectories contain archived pages or separate map applications and
are not required by the root homepage.
